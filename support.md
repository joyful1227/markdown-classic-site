Markdown Classic — Support

Thank you for using Markdown Classic!

Markdown Classic is a simple, offline Markdown editor for macOS, designed for a clean, private, and distraction-free writing experience.

Features

* Simple Markdown editing
* Fully offline functionality
* Editable Markdown preview
* Keyboard shortcuts
* Light and Dark Mode
* Multiple language options
* Personalized settings

Frequently Asked Questions

Does Markdown Classic require an internet connection?

No. Markdown Classic works entirely offline.

Where are my documents stored?

Your documents are stored locally on your Mac.

Does Markdown Classic collect personal data?

Markdown Classic does not collect, track, or upload personal information.

Can I change the app’s appearance?

Yes. You can switch between Light and Dark Mode in Settings.

Does Markdown Classic support keyboard shortcuts?

Yes. Markdown Classic includes keyboard shortcuts for common editing actions.
