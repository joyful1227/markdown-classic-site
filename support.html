Support

Need help with Markdown Classic? Find answers to common questions below.

Does Markdown Classic work offline?

Yes. Markdown Classic works entirely offline. No internet connection is required.

Where are my documents stored?

Your documents are stored locally on your Mac.

Does Markdown Classic collect personal data?

No. Markdown Classic does not collect, track, or upload personal information.

Can I change the appearance?

Yes. Light and Dark Mode are available in the app settings.

Does it support keyboard shortcuts?

Yes. Common Markdown formatting actions can be performed using keyboard shortcuts.
